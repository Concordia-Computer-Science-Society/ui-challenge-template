# Cursed UI/UX Challenge — Starter Template

Welcome! Your mission: build the **most hilariously frustrating user interface** you can.
It still has to *technically work* — the user must be able to complete the task. Eventually.

## The Task
Build a UI where the user can **enter their name and phone number and submit it**.
YOU DON'T HAVE TO USE THE TEMPLATE

## How to Participate
1. Click **"Use this template" → "Create a new repository"** at the top of this page.
2. Name it `CURSED-ui-<your-team-name>` and make it **public**.
3. Pick ONE starter and delete the other folder:
   - `java-starter/` — Java Swing desktop app
   - `web-starter/` — HTML/CSS/JS web page

   Both starters are the same working sign-up form

4. Build your masterpiece.
5. Fill out `SUBMISSION.md`.
6. Submit your repo link before the deadline (see below).

## Rules
- Deadline: **[OCT 31]**
- Teams of up to **[2]** people
- The task must be completable — "impossible" is not the same as "bad"
- Keep it school-appropriate. No malware, no actually crashing someone's computer, no loud audio jumpscares
- Only use code/assets you have the right to use


## Judging
| Category | Points |
|---|---|
