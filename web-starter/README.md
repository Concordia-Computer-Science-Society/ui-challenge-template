# Web Starter (HTML / CSS / JavaScript)

A plain, working sign-up form with a bunch of parts to ruin: text fields, a slider,
a dropdown, radio buttons, a checkbox, buttons and a status message.

## Files
| File | What it is |
|---|---|
| `index.html` | The parts of the page. |
| `style.css` | How it looks. All the colors are at the top, so you can change the whole page at once. |
| `script.js` | What it does: the slider label, the rules, Submit and Clear. Start here. |


Look for `>>> IDEAS` comments in every file for ideas.

## Run it
Double-click `index.html` to open it in your browser. After you change a file, save it and refresh the page.

To share a live link, turn on GitHub Pages: **Settings → Pages → Deploy from branch → `main`**.
Your page will be at `https://<username>.github.io/<repo-name>/web-starter/`.


## Tips
- Press **F12** in your browser to open the developer tools. The **Console** tab shows your errors.
- Keep everything in this folder so judges can open `index.html` and play.
- Bad is the goal. Impossible is not. Make sure a patient person could still submit the form.
